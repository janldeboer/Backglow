2. The Backglow app

With your Screen Recording permission, Backglow captures the selected display through Apple's ScreenCaptureKit. From each frame, the app calculates a few color values for the edge zones and sends only these over the USB serial connection you chose to your LED controller. Images are neither stored nor transmitted.

Settings such as LED layout, color values and the selected display are stored locally in ~/Library/Application Support/Backglow/settings.json. When you explicitly trigger it, Backglow also writes the LED layout and color values to your controller.

The app contains no analytics, advertising or crash reporting services and makes no network connections. We receive no data from the app. You can revoke the permission at any time under System Settings → Privacy & Security. To delete all app data, remove the app and the settings folder named above.

To deliver it, the server infrastructure processes technically necessary data such as IP address, time, requested page and the HTTP request information your browser sends.

We keep no regular access logs for this website and create no visitor profiles. Request data is processed only while the request is handled. If technical data arises in the event of a fault or security incident, we use it only as long as needed to investigate and secure operations. For the infrastructure provider's own processing, see Hetzner's privacy policy.

The website uses no cookies, no local storage, no scripts, no analytics tools and no fonts or content from third parties.
