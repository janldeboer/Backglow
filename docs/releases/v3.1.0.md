**Backglow now runs on macOS 14 Sonoma and later**, not only on macOS 26. On macOS 26 it keeps its Liquid Glass look; on macOS 14 and 15 the cards and the start button use standard macOS materials instead. Everything else, from capture and Metal to the LED controller, is the same on every version.

Support for macOS 14 and 15 is new and has only been checked by building against those versions so far, not on a Mac running them. If something looks or works wrong there, please [open an issue](https://github.com/Janldeboer/Backglow/issues/new/choose) with your macOS version.

**Website and setup guide:** https://backglow.jandeboer.de/en/ · [Deutsch](https://backglow.jandeboer.de/)

## Install

1. Download `Backglow-3.1.0.dmg` below and drag Backglow into Applications.
2. Open Backglow and allow **Screen Recording** when asked, then restart it.

Updating from 3.0.2 keeps your settings and the Screen Recording permission. Flash the firmware and wire the strip as described in the [guide](https://backglow.jandeboer.de/en/docs/).

## Requirements and limitations

- macOS 14 or later on a Mac with Apple silicon. The download is arm64 only; on an Intel Mac, build from source with Xcode 26.
- The controller profile stores the LED layout and the color look (saturation, gamma, brightness, smoothing, channel gains). Color temperature, the eight-color calibration, backlight and power limit stay in the Mac's settings for now.
