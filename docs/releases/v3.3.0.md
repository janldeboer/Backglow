**Backglow now runs on its own.** It can open at login, sits in the menu bar, and switches the lights on as soon as your monitor and LED controller are both connected. A new single-color mode turns the strip into a plain lamp, with a color field and a white slider from cool to warm.

**Website and setup guide:** https://backglow.jandeboer.de/en/ · [Deutsch](https://backglow.jandeboer.de/)

## New

- **Menu bar control:** switch the lights on and off, choose screen or single color, pick a color and set the brightness without opening the window. With the window closed, Backglow keeps running in the menu bar without a Dock icon.
- **Open at login** (Automation page). Started at login, Backglow opens no window.
- **Automatic connection:** connect your controller once, then remember the display and controller as a pair. Whenever both are plugged in, Backglow connects and switches on; when either is unplugged, the lights go off. Only the remembered controller is ever opened automatically: same USB ID and serial number, or the same USB socket for adapters without a serial number. With the v3 firmware its chip ID has to match before any data is sent.
- **Single-color mode:** every LED shows one color and no screen capture is needed. Pick the color from presets, a field for hue and saturation, a white slider from cool (9000 K) to warm (2000 K), or the system color picker, in the window and in the menu bar.
- The LEDs go dark while the displays sleep and when Backglow quits.
- The display picker shows the monitor's name.

## Fixed

- **No more flickering when the Mac is busy.** The color smoothing could swing back and forth after a late output tick, for example while another app kept the CPU or GPU busy. It is now stable for any time step.
- **Backglow throttles itself.** When output ticks come late or frame analysis cannot keep up, Backglow lowers its capture and output rate in steps down to a quarter and raises it again once the Mac has caught up. After a hang it holds the current colors and fades back in once things run smoothly. The Diagnostics page shows the current **Output rate**.
- macOS no longer slows Backglow down with App Nap while the lights are on.
- With the window open, the live preview no longer redraws at the LED rate: CPU load drops from about 90 % to about 20 %.

## Install

1. Download `Backglow-3.3.0.dmg` below and drag Backglow into Applications.
2. Open Backglow and allow **Screen Recording** when asked, then restart it.

Updating from 3.1.0 keeps your settings and the Screen Recording permission.

## Requirements and limitations

- macOS 14 or later on a Mac with Apple silicon. The download is arm64 only; on an Intel Mac, build from source with Xcode 26.
- With several remembered pairs present at the same time, the one already active stays connected, otherwise the first remembered one wins; Backglow does not ask yet.
