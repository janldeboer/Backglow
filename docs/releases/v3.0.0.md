The first release under the name **Backglow**: a native rewrite of the earlier macOS Ambient Lighting app. It mirrors the edges of your Mac's screen onto an LED strip behind the monitor.

**Website and setup guide:** https://backglow.jandeboer.de/en/ · [Deutsch](https://backglow.jandeboer.de/)

## Highlights

- Native SwiftUI app with sidebar and Liquid Glass, in English and German
- ScreenCaptureKit capture and GPU zone averaging with Metal (CPU fallback)
- Live preview with numbered zones and the calculated LED colors
- Letterbox detection that ignores black bars only once they are stable
- Spring smoothing on its own output clock and an anti-flicker filter, following HyperHDR
- Color calibration with eight reference colors, color temperature, minimum backlight and a power limit
- New ESP32/ESP8266 firmware that keeps the LED layout and colors in a profile on the controller; the original `led`/`les` sketch still works
- New Liquid Glass app icon

## Install

1. Download `Backglow-3.0.0.dmg` below and drag Backglow into Applications.
2. Open it once. macOS blocks it because the app isn't notarized yet; go to **System Settings → Privacy & Security** and click **Open Anyway**.
3. Allow **Screen Recording** when asked, then restart Backglow.

Flash the firmware and wire the strip as described in the [guide](https://backglow.jandeboer.de/en/docs/).

## Requirements and limitations

- macOS 26 on a Mac with Apple silicon. The download is arm64 only; on an Intel Mac, build from source.
- Not notarized, signed ad hoc. Because the signature changes with every build, macOS may ask for Screen Recording permission again after an update.
- The controller profile stores the LED layout and the color look (saturation, gamma, brightness, smoothing, channel gains). Color temperature, the eight-color calibration, backlight and power limit stay in the Mac's settings for now.
- Settings from builds named *AmbientLightingV3* are imported on first launch.
